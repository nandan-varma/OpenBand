# OpenBand

Play instruments in the browser — a piano you can play from your keyboard, with realistic sounds and a recorder to replay what you played back.

## Features

- Piano playable from your keyboard
- Realistic instrument sounds via [Soundfont Player](https://github.com/danigb/soundfont-player) (General MIDI soundfonts)
- Recorder to capture and replay what you played

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Built with

- [Next.js](https://nextjs.org) (Pages Router)
- [react-piano](https://github.com/kevinsqi/react-piano) — keyboard UI
- [soundfont-player](https://github.com/danigb/soundfont-player) — General MIDI instrument sounds
- Tailwind CSS
- TypeScript
